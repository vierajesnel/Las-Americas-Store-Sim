# Las Americas: Authorized Chaos

A pixel-art shift at the store. Customers walk in with a need (bill question, a
case, a new phone) and wait in line, on the sofa, or browsing the demo tables.
Tap one to help them: solve the puzzle before their patience runs out, then
the crew member walks them to the right station to finish up. Make as much as
you can before 9 PM.

Built with Phaser 4, TypeScript and Vite. Plays in a phone browser held
sideways; add it to the home screen for full screen.

## Run it

```sh
npm install
npm run dev        # http://localhost:5173, also on your network for phones
npm test           # unit tests (pathfinding, puzzles, shift math)
npm run build      # typecheck + production build in dist/
```

## Playtest in a headless browser

```sh
npm run build && npx vite preview --port 4173 &
node scripts/playtest.cjs playtest-out 4 120   # out dir, floor speed, seconds
```

`?debug` in the URL exposes `window.game`, marks puzzle answers for the
script, and `&speed=4` runs the floor 4x faster (puzzles stay real-time).

## Where things live

- `src/scenes/ShiftScene.ts`: the shift: spawning, waiting spots, patience,
  jobs at stations, the clock
- `src/world/`: people on the floor (walking, animation, bubbles, bars)
- `src/puzzles/`: puzzle generators; `src/ui/puzzleView.ts` draws them
- `src/ui/`: HUD, punch clock, pause and summary (HTML over the canvas)
- `src/data/layout.ts`: every spot on the floor; `props.json` comes from the art
- Art is generated by the Python scripts in `../art` (`build_sprites.py`,
  `store_map/make_map.py`), which write into `public/assets` and `src/data`.
